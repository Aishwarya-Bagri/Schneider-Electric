FactoryOS design artefacts

Supporting design pack for the FactoryOS prototype: wireframes, data model, process flow and deployment schematic. It uses the same four engines, the same entities and the same blocks as the system architecture diagram and the working prototype. Print to PDF for submission.

1. UX wireframes

Screen A is the working prototype. Screen B is its Stress test tab. Screen C, a phone approval view, is planned for pilots so owners can accept actions away from a desk.

2. Data model

Each entity maps to a block in the architecture. Meter readings come from the plant-floor sensors through the edge gateway. Orders and tariff come from the business systems. Plans and recommendations are produced by the four engines.

3. Process flow

The daily planning loop, split by who acts at each step. FactoryOS only recommends. The manager decides.
